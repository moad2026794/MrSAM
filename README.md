# مستر سام — معلم الإنجليزية الافتراضي 🎓

تطبيق أندرويد (Kotlin + Jetpack Compose) يعطيك **درسًا يوميًا مدته ساعة** مع معلم افتراضي اسمه «مستر سام».

## الفكرة: ساعة = ٦ فقرات × ١٠ دقائق

| # | الفقرة | ما يحدث |
|---|--------|---------|
| 1 | 🔥 إحماء ومراجعة | اختبار سريع لكلمات الأيام السابقة (أو إحماء نطق في اليوم الأول) |
| 2 | 📚 مفردات اليوم | ٨ كلمات: نطق + مثال + معنى عربي + اختبار |
| 3 | 🧩 قاعدة اليوم | شرح بالعربية مع أمثلة منطوقة وتمارين |
| 4 | 🎧 استماع وفهم | نص يُقرأ بصوت المعلم (عادي/بطيء) وسؤال فهم |
| 5 | 🎤 نطق | تكرّر الجمل ويقيّم التطبيق كم كلمة نطقتها |
| 6 | 💬 حوار مع المعلم | محادثة (كتابة أو صوت) — حرّة مع Claude أو بأسئلة جاهزة |

التحفيز: سلسلة أيام متتالية 🔥، نقاط ⭐، دقائق دراسة ⏱، وتذكير يومي بالإشعارات.
المستويات: A1 (مبتدئ)، A2 (أساسي)، B1 (متوسط).

## البناء على GitHub (بدون Android Studio)

1. أنشئ مستودعًا جديدًا على github.com.
2. ارفع **محتويات** المجلد `MisterSam` إلى المستودع (بما فيها المجلد المخفي `.github`). الرفع بالسحب والإفلات من متصفح الكمبيوتر، أو عبر `git push`.
3. افتح تبويب **Actions** ← سير العمل **Build APK** (يبدأ تلقائيًا عند الرفع، أو اضغط *Run workflow*).
4. بعد نجاحه (حوالي 5–8 دقائق أول مرة) افتح تشغيله ونزّل **MisterSam-debug-apk** من قسم Artifacts، ثم فكّ الضغط وثبّت `app-debug.apk` على هاتفك (فعّل «التثبيت من مصادر غير معروفة»).

إن فشل البناء فانسخ آخر سطور الخطأ من Actions وأرسلها لي لأصلحها.

## التشغيل

1. افتح مجلد `MisterSam` في **Android Studio** (Ladybug أو أحدث) واترك Gradle يزامن المشروع.
2. شغّل على جهاز حقيقي أو محاكي (Android 8.0+ / API 26).
3. للنطق والاستماع: يلزم وجود محرك TTS وخدمة التعرف على الكلام من Google على الجهاز.
4. (اختياري) للمحادثة الحرة: الإعدادات ← أدخل مفتاح Claude API.

## بنية الكود

```
app/src/main/java/com/mistersam/app/
├─ MainActivity.kt
├─ data/   Models.kt (النماذج والفقرات) · Content.kt (الدروس) · Store.kt (DataStore)
├─ util/   Speech.kt (TTS + STT + تقييم النطق) · Reminder.kt (WorkManager)
├─ ai/     Teacher.kt (Claude API + ردود احتياطية)
└─ ui/     Screens.kt (الرئيسية/الاستقبال/الإعدادات) · Session.kt (الفقرات الست)
          Widgets.kt · AppViewModel.kt · Theme.kt
```

لإضافة درس جديد: أضف عنصر `Lesson(...)` إلى القائمة المناسبة في `Content.kt`.

## ملاحظات مهمة

- **لم يُجرَّ بناء (compile) للمشروع** في بيئة الكتابة لعدم توفر Android SDK؛ قد تظهر أخطاء صغيرة عند أول مزامنة يسهل إصلاحها.
- المحتوى المضمّن الآن: ٥ دروس A1 و٣ دروس A2 و٢ دروس B1 (تتكرر عند النهاية). التوسّع بإضافة دروس أو توليدها بالذكاء الاصطناعي.
- تقييم النطق يعتمد على مطابقة الكلمات التي تعرّف عليها المحرك، وليس تحليلًا صوتيًا دقيقًا.
- مفتاح API يُحفظ على الجهاز. للنشر العام الأفضل تمرير الطلبات عبر خادم وسيط بدل وضع المفتاح داخل التطبيق.
- لم أُضف أيقونة تطبيق؛ أنشئها من Android Studio: New ← Image Asset.

## أفكار للتطوير

اختبار تحديد المستوى، مراجعة متباعدة (Spaced Repetition) حقيقية، حفظ تقدّم الجلسة عند الخروج، دروس مولَّدة يوميًا بحسب أخطائك، ومؤقّت يضمن إكمال الساعة.
